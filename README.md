# Rohan Ahire — Portfolio

Brutalist magazine personal site. Showcase of six real builds.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Fonts: Archivo Black · Newsreader · Space Mono

## Projects featured

1. **Flaggo** — geography game (Vite/React/Supabase)
2. **Coachmate** — Chess.com coaching (Next.js + Stockfish)
3. **Multibagger** — NSE SEPA scanner (Python/Polars/DuckDB)
4. **Extracta** — document → JSON demo
5. **WA Cleaner** — Android duplicate media (Expo)
6. **Clenow NSE** — momentum strategy backtest

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit content

All copy lives in `src/lib/content.ts` — email, links, project blurbs.
